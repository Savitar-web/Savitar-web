## Cómo trabajamos

1. Entendemos el proceso, los usuarios y el objetivo.
2. Acordamos módulos, integraciones, entregables y criterios de aceptación.
3. Diseñamos y desarrollamos por hitos revisables.
4. Validamos los recorridos acordados y definimos entrega, soporte y siguientes fases.

**Proyectos a medida desde $100,000 MXN**, sujetos a diagnóstico y alcance. Las propuestas detallan costos recurrentes, servicios de terceros y condiciones de entrega.
